### A fast, lightweight Python utility for viewing  NMR data processed with NMRpipe. 


## Installation

```
pip install -r requirements.txt 

python NMRdraw_lite.py [file1.ft file2.ft ...]
```

## Example Data
The `example/` directory contains sample dataset from my laboratory.
 

## Standalone MacOS App
A MacOS application for all Apple Silicon computers is available in the **Releases** directory.

## Acknowledgements
Thank you to **Dr. Frank Delagio** (IBBR / U Maryland) for the original NMRdraw that has been used for decades and **Dr. Johnthan Helmus** (www.nmrglue.com) for the nmrglue framework that powers all the visualization and NMR data formats. 

## Features
**1D Spectra:** stack plots with variable offsets

**2D Spectra:** quick visualization of titrations

**3D Spectra:** fast scrolling through planes
